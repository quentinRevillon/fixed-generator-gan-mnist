# Report sources

`../docs/report.pdf` is built from this directory (upload it as an Overleaf project, or run `latexmk -pdf main.tex`). Compile `main.tex` with pdfLaTeX and BibTeX.
The report uses the ACM `sigconf` format (`acmart` class, shipped with TeX Live and Overleaf) with the `nonacm` option.

- `main.tex`: title, authors, keywords and section assembly; the supplementary material follows the AI use statement, in one column.
- `sec_merge/`: abstract and one `.tex` file per section (introduction, related work, setup, methods, results, discussion, conclusion, AI use statement, `8_supplementary.tex`).
- `tabs/supp/`, `figs/supp/`: tables and figures of the supplementary material, generated by `regenerate_supplementary.py` (needs `torch`, `matplotlib`, `pyyaml` and the trained generators in `../runs/`).
- `tabs/`: data lever, loss x EMA, rejection sampling, and the full-width table of all configurations. Each file starts with the CSV it comes from.
- `figs/`: figures drawn by the group's scripts (`rapport/report/figscripts/` on the branch `quentin/comparaison`).
- `data/`: the result CSVs behind every number of the report.
- `regenerate_figures.py`: copies the figures and CSVs from the repository (after `git fetch`) and recomputes every mean, standard deviation, collapse count and p-value quoted in the report. Run `python3 report/regenerate_figures.py`; p-values need `scipy`.
- `references.bib`: bibliography database (`ACM-Reference-Format` style).

Current length: a group cover page (not counted), then five pages, references and AI use statement included (A2 limit: five pages of content), followed by 12 pages of supplementary material (mathematical details, training dynamics, generated examples, full per-seed tables, reproducibility).
